# DiscFit Release Package

This package contains the following:

1. **Source Code**: `source_code.zip`
   - Includes all necessary source files for the DiscFit project.

2. **Binary Files**: `binary_files.zip`
   - Contains the compiled binaries for the DiscFit application.

## Instructions

- Extract `source_code.zip` to view or modify the source code.
- Extract `binary_files.zip` to access the compiled application ready for deployment.

## Notes

Ensure you have .NET 8 installed to build or run the application from source.
